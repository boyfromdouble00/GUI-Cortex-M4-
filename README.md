Local LLM 기반 스마트 신호등·차단봉 V9 (PA8 ECHO 수정)
NUCLEO-F411RE가 신호등, SG90 서보 차단봉, HC-SR04 초음파 센서와 부저를 실시간 제어하고, Windows PC의 PyQt GUI와 로컬 LLM이 상태 설명·자연어 명령·최근 사고 요약을 담당하는 프로젝트입니다.

완성 동작
전원 인가 기본 상태: 빨간불 ON, 차단봉 0° 닫힘
차단봉 열기: 노란불과 함께 90° 이동 후 초록불 ON
열림 유지: 10초 후 자동 닫힘
초음파 장애물 감지: 빨간불 ON, 차단봉 0° 닫힘, 부저 0.5초 1회
오검출 억제: 100 ms 간격으로 2회 연속 감지할 때 비상 동작
비상 우선순위: 초록불 명령보다 STM32 초음파 FSM이 항상 우선
AI 채팅 제어: 초록불 전환만 허용, 빨간불·주황불·노란불 변경 명령은 차단
최근 사고: GUI가 장애물 사고 최근 3건만 PC_GUI/recent_accidents.json에 보관
로컬 LLM: 상태 설명, 최근 3건 사고 요약, 로그 분석, 감지 거리 및 자동 복귀 시간 설정
필요한 부품
NUCLEO-F411RE
SG90 또는 동급 5V 서보모터 1개
HC-SR04 초음파 센서 1개
빨강·노랑·초록 LED 각 1개
LED용 220~330Ω 저항 3개
HC-SR04 ECHO 분압용 1kΩ, 2kΩ 저항 각 1개
HIGH 신호 입력형 액티브 부저 모듈 1개
외부 5V 2A 전원, 브레드보드, 점퍼선
선택: 서보 전원 안정화용 470~1000µF 전해콘덴서
배선은 반드시 전원을 끈 상태에서 먼저 완료하십시오. 전체 연결은 docs/WIRING.md에 있습니다.

Windows 실행 순서
1. 펌웨어 업로드
NUCLEO의 ST-LINK USB를 PC에 연결한 뒤 프로젝트 최상위 폴더의 아래 파일을 더블클릭합니다.

1_UPLOAD_FIRMWARE.bat
SUCCESS: FIRMWARE UPLOAD COMPLETE가 나오면 완료입니다. 이 스크립트는 일반 python 대신 %USERPROFILE%\.platformio\penv\Scripts\platformio.exe를 우선 사용하므로 MSYS2 Python 문제를 피합니다.

2. Local LLM 준비
https://ollama.com/download/windows 에서 Ollama for Windows 설치
Windows 시작 메뉴에서 Ollama를 한 번 실행
프로젝트의 4_SETUP_LOCAL_LLM.bat 더블클릭
qwen2.5:3b 다운로드 완료 대기(약 1.9GB)
LLM을 사용하지 않아도 STM32 제어와 GUI는 정상 작동합니다.

3. GUI 실행
2_RUN_GUI.bat
GUI에서 STMicroelectronics STLink Virtual COM Port를 선택하고 연결을 누릅니다. 정상 연결되면 STATE:CLOSED, GATE:0, 거리 값 등이 수신됩니다.

4. AI 관리자 사용 예
지금 왜 빨간불이야?
초록색으로 바꿔줘.
감지 거리를 30cm로 바꿔줘.
장애물이 사라진 뒤 5초 후 열어줘.
최근 사고 3건 요약해줘.
최근 로그에 센서 값이 튄 부분이 있는지 분석해줘.
초록색으로 바꿔줘는 GATE_OPEN 요청으로 변환됩니다. STM32가 현재 초음파 센서 값을 먼저 검사하며 장애물이 기준 거리 안에 있거나 센서 응답이 없으면 열지 않습니다. 열리는 도중에도 장애물이 2회 연속 감지되면 즉시 비상 닫힘이 실행됩니다.

AI 채팅에서 빨간불·주황불·노란불로 바꾸라는 요청은 실행되지 않습니다. 차단봉을 직접 닫아야 할 때는 GUI의 차단봉 닫기 (0°) 버튼을 사용하십시오.

빠른 점검
LD2가 0.5초마다 깜빡임: 펌웨어 메인 루프 정상
외부 빨간 LED 계속 켜짐: 기본 닫힘 상태 정상
GUI 거리 센서 응답 없음: ECHO가 D7(PA8)의 분압 노드에 연결됐는지와 공통 GND 확인
GUI 보드 응답 없음: COM 포트, 115200 baud, 최신 펌웨어 확인
Ollama 연결 실패: Windows 트레이에서 Ollama 실행 여부와 모델명 qwen2.5:3b 확인
서보 동작 때 보드 리셋: 서보 외부 5V 전원 용량과 공통 GND 확인
안전 주의
이 프로젝트는 교육·모형용입니다. 요구사항에 따라 장애물 감지 시 차단봉이 닫히도록 구현되어 있으므로 실제 사람이나 차량이 통과하는 장치에 그대로 사용하면 위험합니다. 실장 장비에서는 차단봉 아래 별도 안전 센서, 기계식 리미트, 비상 정지 및 인증된 제어기를 추가해야 합니다.
